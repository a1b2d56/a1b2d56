## About

Computer science student focused on native Android development. My work centers on Kotlin, Jetpack Compose, and Clean Architecture, with an emphasis on writing code that's secure and easy to build on. I'm equally interested in interface design — making sure what I build is as clear to use as it is to maintain.

## Projects

### [Spectre](https://github.com/a1b2d56/Spectre)
A Bitwarden client for Android built with Kotlin, Jetpack Compose, and Clean Architecture. Currently in progress, with a focus on security, performance, and interface quality.

### [Planora](https://github.com/a1b2d56/planora)
A native Android productivity app that combines notes, tasks, and personal finance — including automatic transaction logging from bank SMS — into a single offline-first, encrypted application built with Kotlin and Jetpack Compose.

### [Ex-Employee](https://github.com/a1b2d56/Ex-Employee)
An ex-employee management portal for Power Grid Corporation of India, built with Kotlin, XML views, Clean Architecture, and Hilt.

### [Helix](https://github.com/a1b2d56/Helix)
A multi-threaded download manager for Windows, built with C# and WPF. Supports segmented HTTP downloads, torrents, HLS streams, and YouTube extraction, with a companion browser extension for capturing downloads directly.

### [MultiAI](https://github.com/a1b2d56/MultiAI)
A Windows desktop application that unifies multiple AI providers — including ChatGPT, Gemini, and Claude — behind one interface, built in C#.

### [BypassTPM-SecureBoot](https://github.com/a1b2d56/BypassTPM-SecureBoot)
A registry-based utility for installing Windows 11 on hardware that doesn't meet the official TPM and Secure Boot requirements. Picked up by other developers solving the same problem — 13 stars to date.

### [Midjourney Scraper](https://github.com/a1b2d56/midjourney_scrapper)
A Python tool that uses the Midjourney API to generate and collect high-resolution images.

### [PixelGuard](https://github.com/a1b2d56/PixelGuard)
A Python toolkit for pixel-level image processing, including watermarking and batch operations.
